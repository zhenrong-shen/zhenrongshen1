# 채용공고 근로자성 리스크 워딩 점검 도구

알바몬·잡코리아 등에 올라온 "동화세상에듀코" 채용공고에서 근로자성(위장도급) 인정
위험이 있는 표현을 찾아 "현재워딩 → 수정/삭제 제안" 형태로 안내하는 Streamlit 앱입니다.

## 주요 기능

- **텍스트 붙여넣기** / **사이트 주소(URL) 입력** / **화면 캡쳐 이미지 업로드(OCR)** 로 공고 내용을 입력
  - URL을 입력하면 해당 페이지의 본문 텍스트를 자동으로 가져옵니다. 단, 로그인이
    필요하거나 자바스크립트로 내용을 렌더링하는 사이트는 본문을 가져오지 못할
    수 있으며, 이 경우 화면 캡쳐 이미지 업로드로 대체하세요.
  - 공고가 길어 한 화면에 다 안 잡히는 경우, 여러 장으로 나눠 캡쳐해 업로드하면
    업로드 순서대로 이어붙여 한 건으로 분석합니다.
  - URL/OCR로 가져온 텍스트는 화면에서 바로 수정할 수 있어 본문과 무관한 내용이나
    인식 오류를 보정할 수 있습니다.
- **위험 워딩 사전 대조**: `risk_checker/risk_dictionary.json`에 등록된 규칙과
  대조하여 위험도(상/중/하), 분류, 판단 근거, 수정·삭제 제안을 표로 보여줍니다.
- **사전 관리 화면**: 앱 내에서 위험 워딩 규칙을 직접 추가·수정·삭제할 수 있습니다.

> ⚠️ 본 도구는 사전에 등록된 규칙 기반으로 동작하는 참고용 점검 도구입니다.
> 사전에 없는 새로운 위험 표현은 자동으로 탐지되지 않으며, 최종 게시 전에는
> 노무 전문가의 검토를 받으시기 바랍니다.

## 설치 및 실행

### 1) 시스템 요구사항 (OCR용 Tesseract)

이미지 업로드 기능을 사용하려면 시스템에 Tesseract OCR(한국어 언어팩 포함)이
설치되어 있어야 합니다.

```bash
# Ubuntu/Debian
sudo apt-get install -y tesseract-ocr tesseract-ocr-kor
```

텍스트 붙여넣기 기능만 사용한다면 Tesseract 설치 없이도 동작합니다.

### 2) Python 패키지 설치

```bash
pip install -r requirements.txt
```

### 3) 앱 실행

```bash
streamlit run app.py
```

브라우저가 자동으로 열리며, 안내에 따라 텍스트를 붙여넣거나 캡쳐 이미지를
업로드해 분석을 실행하면 됩니다.

## 위험 워딩 사전 커스터마이징

`risk_checker/risk_dictionary.json` 파일 또는 앱의 "위험 워딩 사전 관리" 탭에서
규칙을 추가·수정할 수 있습니다. 각 규칙은 다음 항목으로 구성됩니다.

| 필드 | 설명 |
| --- | --- |
| `id` | 규칙 고유 번호 (예: R001) |
| `category` | 위험 유형 분류 (예: 출퇴근/근무시간 통제) |
| `risk_level` | 상/중/하 |
| `keywords` | 탐지할 표현 목록 (쉼표로 구분, 공백 차이는 자동 무시) |
| `reason` | 왜 위험한지에 대한 판단 근거 |
| `suggestion` | 수정 또는 삭제 제안 문구 |

회사에서 정리해 둔 금지어/권장 대체 문구 목록이 있다면 이 형식에 맞춰
채워 넣으면 됩니다.

## 프로젝트 구조

```
app.py                          # Streamlit 앱 (UI)
risk_checker/
  fetcher.py                    # URL → 본문 텍스트 추출 (requests + BeautifulSoup)
  ocr.py                        # 이미지 → 텍스트 OCR (Tesseract, 전처리 포함)
  rules.py                      # 위험 워딩 사전 로드/저장
  analyzer.py                   # 텍스트 ↔ 사전 매칭 엔진
  risk_dictionary.json          # 기본 위험 워딩 사전 (편집 가능)
tests/
  test_analyzer.py              # 매칭 엔진 단위 테스트
  test_fetcher.py               # URL 텍스트 추출 단위 테스트
```

## 다른 OCR/AI 엔진으로 교체하고 싶다면

기본값은 무료·오프라인인 Tesseract이지만, `risk_checker/ocr.py`의
`extract_text()` 함수만 교체하면 Naver Clova OCR, Claude API 등 다른 엔진으로
쉽게 바꿀 수 있도록 인터페이스를 분리해 두었습니다.
